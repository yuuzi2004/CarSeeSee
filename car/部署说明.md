## 环境要求

- Python 3.8 或更高版本
- CUDA（如果使用 GPU，推荐）
- 至少 4GB 内存
- 磁盘空间：至少 2GB（用于模型和依赖）

## 安装依赖

### 1. 创建虚拟环境（推荐）

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

### 2. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

**注意**：如果使用 GPU，确保已安装对应版本的 PyTorch（支持 CUDA）

```bash
# 检查 GPU 是否可用
python -c "import torch; print(f'GPU可用: {torch.cuda.is_available()}')"
```

## 启动服务

### 方式一：直接运行（开发环境）

```bash
python app.py
```

服务将在 `http://localhost:5000` 启动

### 方式二：使用 Gunicorn（生产环境，推荐）

```bash
# 安装 Gunicorn
pip install gunicorn

# 启动服务（Windows 不支持，使用 waitress）
pip install waitress
waitress-serve --host=0.0.0.0 --port=5000 app:app
```

### 方式三：使用 uWSGI（Linux/Mac 生产环境）

```bash
pip install uwsgi
uwsgi --http :5000 --wsgi-file app.py --callable app
```

## API 接口说明

### 1. 健康检查

**GET** `/health`

**响应示例**：
```json
{
  "status": "ok",
  "message": "YOLOv8 API服务运行正常",
  "model_loaded": true
}
```

### 2. 图片检测（返回检测结果）

**POST** `/predict`

**请求方式**：
- **方式一**：JSON 格式（base64 编码图片）
  ```json
  {
    "image": "data:image/jpeg;base64,/9j/4AAQSkZJRg..."
  }
  ```

- **方式二**：multipart/form-data（文件上传）
  ```
  file: [图片文件]
  ```

**响应示例**：
```json
{
  "success": true,
  "detections": [
    {
      "class_id": 1,
      "class_name": "talking_on_phone",
      "confidence": 0.95,
      "bbox": {
        "x1": 100.5,
        "y1": 200.3,
        "x2": 300.8,
        "y2": 400.2
      }
    }
  ],
  "count": 1,
  "image_shape": {
    "height": 640,
    "width": 480
  }
}
```

### 3. 图片检测（返回标注后的图片）

**POST** `/predict_with_image`

**请求方式**：同 `/predict`

**响应示例**：
```json
{
  "success": true,
  "annotated_image": "base64编码的图片字符串",
  "detections": [...],
  "count": 1
}
```

## 常见问题

### 1. 模型加载失败

**错误**：`FileNotFoundError: 模型文件不存在: yolov8n.pt`

**解决**：
- 确保 `yolov8n.pt` 文件在 `app.py` 同一目录下
- 检查文件路径是否正确

### 2. CUDA 相关错误

**错误**：`CUDA out of memory` 或 `CUDA not available`

**解决**：
- 如果使用 CPU：在代码中指定 `device='cpu'`
- 如果使用 GPU：确保安装了支持 CUDA 的 PyTorch 版本

### 3. 端口被占用

**错误**：`Address already in use`

**解决**：
- 修改 `app.py` 中的端口号（默认 5000）
- 或关闭占用端口的程序

### 4. 依赖安装失败

**解决**：
- 使用国内镜像源：
  ```bash
  pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```

### 5. 跨域问题

**说明**：代码中已启用 CORS，允许跨域请求。如果仍有问题，检查 Flask-CORS 是否正确安装。

## 测试服务

### 使用 curl 测试

```bash
# 健康检查
curl http://localhost:5000/health

# 图片检测（文件上传）
curl -X POST -F "file=@test_image.jpg" http://localhost:5000/predict_with_image
```

### 使用 Python 测试

```python
import requests

# 健康检查
response = requests.get('http://localhost:5000/health')
print(response.json())

# 图片检测
with open('test_image.jpg', 'rb') as f:
    files = {'file': f}
    response = requests.post('http://localhost:5000/predict_with_image', files=files)
    print(response.json())
```

## 性能优化建议

1. **使用 GPU**：如果有 GPU，确保 PyTorch 使用 CUDA
2. **模型量化**：可以尝试模型量化以减少内存占用
3. **批处理**：如果需要处理多张图片，考虑实现批处理接口
4. **缓存**：对于重复请求，可以添加缓存机制

## 下一步

部署完成后，确保 Spring Boot 应用中的 `application.properties` 配置了正确的 Flask API 地址：

```properties
flask.api.url=http://localhost:5000
```

然后启动 Spring Boot 应用即可使用。
